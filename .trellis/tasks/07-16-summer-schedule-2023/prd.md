# 构建 2023 级暑期课表

## Goal

在 `summer-schedule` 分支交付独立的 2026 年暑期社会实践课表。课表数据完全来自指定教学日历和见习轮转表，不沿用当前学期的课程、ABCD 分组或课表缓存。

## Requirements

- 覆盖 2026-07-15 至 2026-09-04 的 8 周暑期安排，并使周次与实际日期正确对应。
- 录入所有岗前培训、每周二专题讲座、周四技能培训/考核，以及第 2 至第 8 周的 1–7 组轮转见习。
- 组别仅为 `1组` 至 `7组`；每周四技能培训和考核按全体共同课程处理，不保留 A–D 分组。
- 课程使用源文件中的真实起止时间；见习、讲座、技能培训与晚间课程均能正确显示、识别当前课程并触发提醒。
- 课表首页改为移动端真实时间视图：标题栏沿用当前代码的信息结构，选择周次、日期和组别后，主内容先显示当前课程，再以统一日表展示当天全部课程；不再以固定节次为主视图。
- 设置页匹配当前代码的卡片结构：快速选择周数、提醒、展开的 1–7 组、直接选择的 M3/简约蓝主题、课表更新和重置。默认主题为简约蓝；不得展示选修课、A–D 分组或显示模式菜单；暑期版本只提供时间轴。
- 暑期版本使用独立主题存储，首次打开和从旧版切换时均默认使用简约蓝；用户在暑期版本内主动选择 M3 后仍应保存该选择。
- 课表页支持左右滑动切换前后一个工作日：周一向右连续进入上周五，周五向左连续进入下周一；在第 1 周周一和第 8 周周五停止，不循环。
- 右上角组别选择器不得使用会被系统重绘为方形的原生 `select`。触发器保持固定胶囊形态，展开 Base UI 风格的无头浮层菜单，以 4+3 网格展示 1–7 组，并支持当前项高亮、点击外部关闭和 Escape 关闭。
- 简约蓝主题下的组别触发器使用比主强调色更低饱和度的蓝色，保持白字可读性且不抢夺课表内容焦点。
- 点击课程时展示课程详情弹窗，包含名称、真实时间、地点、教师、适用对象、备注及编辑/删除操作。
- 课表数据与旧版内置、远端和自定义课表缓存隔离，确保旧课程不能在暑期版本中恢复。
- 不在课表内存储见习联系人的姓名或电话号码。
- 应用每个本地自然日首次启动时检查一次新 Release；仅有新版本时显示包含版本号和 Release 说明的全局弹窗，支持“稍后”和“立即更新”。网络失败静默处理并在 3 分钟后允许重试，设置页仍可手动检查。
- 启动更新检查作为 `2.1.1` 的补充功能，不再提高版本号。

## Acceptance Criteria

- [ ] 第 1 周从 2026-07-13（周一）开始计算，且教学日历中的 7 月 15 日课程显示在第 1 周周三。
- [ ] 第 2 至第 8 周中，每一组均只显示其来源表对应的轮转地点；共同课程对所有组可见。
- [ ] 课表、课程详情、当前课程进度、通知和 Android 小组件均使用课程的真实起止时间。
- [ ] 首页和设置页与已确认的 Pencil 稿在信息层级和交互上保持一致，且移动端可访问。
- [ ] 首页具有日期切换，右上角是唯一的 1–7 组入口；当前课程位于主内容区而非标题栏，下方统一日表按“时间 / 课程 / 地点”展示当天全部课程，并高亮正在进行的对应行。
- [ ] 日期区域可左右滑动切换工作日并连续跨周；边界不会越过第 1 周周一或第 8 周周五，纵向滚动和课程点击不被误触发。
- [ ] 组别触发器在关闭、按下和展开状态均保持协调的胶囊外形；浮层为 4+3 网格，具备 `aria-haspopup`、展开状态和键盘关闭能力。
- [ ] 未保存过暑期主题时默认简约蓝，旧版通用主题键不会让暑期版本首次打开为 M3；暑期版本内的主题选择仍可持久化。
- [ ] 上午见习和下午共同课程使用同一套日表行样式；界面不按课程类型凭空添加“专题讲座”等分区标题，也不显示冗余的“精确时段”标识。
- [ ] 从旧版本升级或本地存在旧课表缓存时，暑期版本不显示旧课程；覆盖安装后，旧远端快照不得覆盖时间相同或更新的新版内置课表。
- [ ] 自动化测试覆盖 1–7 组受众筛选、关键日期/时间映射和轮转数据；构建与现有单元测试通过。
- [ ] 同一自然日只自动请求并提示一次新版本；关闭弹窗后当日不再提示，Android 优先打开 APK，其他平台打开 Release 页面。
- [ ] Web、Android 与项目元数据中对外版本号保持为 `2.1.1`。
