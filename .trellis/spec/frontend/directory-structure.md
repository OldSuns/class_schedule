# Directory Structure

> How frontend code is organized in this project.

## Overview

This is a single React 19 and Vite application. It has no router or package-level feature modules. Files are grouped by technical responsibility, with domain subdirectories where that improves navigation.

## Directory Layout

```text
src/
|-- app/                 # Root orchestration (`App.jsx`)
|-- components/
|   |-- exams/           # Exam UI
|   |-- layout/          # App shell, header, navigation, toast, dialogs
|   |-- schedule/        # Timetable and course editor UI
|   |-- settings/        # Settings page and settings sections
|   `-- shared/          # Reused presentational controls
|-- config/              # Shared constants and storage keys
|-- data/                # Canonical built-in schedule data
|-- hooks/
|   |-- notifications/   # Notification state and scheduling coordination
|   |-- schedule/        # Schedule source, loading, and persistence
|   |-- semester/        # Semester date and current-week state
|   `-- ui/              # Focused UI behavior and preferences
|-- services/
|   |-- app/             # Release update I/O
|   |-- notifications/   # Capacitor notification operations
|   |-- platform/        # Native bridges and platform utilities
|   `-- schedule/        # Remote schedule I/O
|-- styles/              # Shared theme tokens
|-- utils/               # Pure schedule and exam logic
|-- index.css            # Global CSS and Tailwind entry
`-- main.jsx             # React entry point

storage.js               # Web/Capacitor persistence adapter
tests/                   # Node test runner tests
scripts/                 # Export and version synchronization scripts
android/                 # Capacitor Android shell and native bridges
```

## Module Ownership

- `src/app/App.jsx` composes cross-feature state and passes data and callbacks to pages and dialogs. Do not move reusable domain calculations into it.
- Components render UI and emit actions. Examples are `src/components/schedule/CourseTable.jsx`, `src/components/exams/ExamPage.jsx`, and `src/components/settings/SettingsPage.jsx`.
- Hooks own stateful behavior and lifecycle work. Examples are `src/hooks/ui/useTheme.js`, `src/hooks/semester/useSemesterDate.js`, and `src/hooks/schedule/useScheduleData.js`.
- Services own network, Capacitor, and native bridge calls. Examples are `src/services/schedule/remoteSchedule.js`, `src/services/notifications/notificationScheduler.js`, and `src/services/platform/widgetBridge.js`.
- Utilities hold pure normalization and business logic. Examples are `src/utils/schedule/scheduleUtils.js`, `src/utils/schedule/timeUtils.js`, and `src/utils/exam/examUtils.js`.
- `src/data/scheduleData.js` is the built-in schedule source of truth. The root `schedule.json` is generated by `npm run export-schedule`; do not edit it as an independent source.

## Naming Conventions

- React component files and component identifiers use PascalCase and `.jsx`, for example `CourseTable.jsx` and `RemoteUpdateConfirmDialog.jsx`.
- Hook files and exports start with `use`, for example `useWeekSelector.js` and `useNotifications.js`.
- Services and utilities use descriptive camelCase `.js` names, for example `fetchWithTimeout.js` and `examUtils.js`.
- Components normally use a default export. Hooks, services, utilities, and constants use named exports.
- Keep a component-specific group together in a directory when it already has several files, as with `src/components/schedule/CourseModal/` and `src/components/settings/SettingsMenu/`.

## Placement Examples

```jsx
// src/components/layout/Header.jsx
const Header = ({ currentWeek, onWeekChange }) => { /* render only */ };
export default Header;
```

```js
// src/hooks/ui/useWeekSelector.js
export const useWeekSelector = (initialWeek = 1) => { /* stateful behavior */ };
```

```js
// src/utils/exam/examUtils.js
export const sortExamsByStart = (exams) =>
  [...(Array.isArray(exams) ? exams : [])].sort(/* pure comparison */);
```

Do not add new flat `src/*.js` feature files, duplicate `storage.js`, or create a second built-in schedule source.
